# Supply Chain Network Optimization for Anadolu Efes

## Overview

This project uses Linear Programming (LP) and Mixed Integer Programming (MIP) to optimize the supply chain network of Anadolu Efes, one of the largest beverage manufacturers in the region.

## Business Problem

Anadolu Efes needed to reduce transportation costs while determining the optimal long-term strategy for brewery expansion and distribution network design.

## Objectives

### Short-Term

Minimize transportation costs through optimized shipment planning.

### Long-Term

Determine optimal brewery expansion locations while minimizing total system costs.

## Methodology

### Linear Programming

Optimized:

- Malt shipments
- Brewery production allocation
- Beer distribution routes

Subject to:

- Capacity constraints
- Demand satisfaction
- Yield conversion requirements

### Mixed Integer Programming

Added decisions for:

- Opening new breweries
- Expanding existing facilities
- Capital investment planning

## Results

### Short-Term Optimization

- Reduced transportation costs to $11.8M
- Achieved approximately 16.7% cost savings

### Long-Term Optimization

Optimal expansion strategy:

- Open Izmir Brewery
- Open Samsun Brewery
- Open AnkNew Brewery
- Expand Izmir facility

Total optimized system cost:

- $23.56M

## Scenario Analysis

Evaluated:

- Alternative facility locations
- Capacity reductions
- Expansion restrictions
- Demand fluctuations

## Tools Used

- Excel Solver
- Linear Programming
- Mixed Integer Programming
- Sensitivity Analysis

## Business Impact

The project provided a data-driven expansion strategy capable of reducing logistics costs while improving network efficiency and scalability.
